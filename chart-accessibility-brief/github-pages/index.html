TAYLER ERBE / RESEARCH BRIEF · ACCESSIBLE CHARTS

If you have the data, describe the chart from the data.

I first built accessible chart descriptions with AI. Then I read the research. Even the best models still get chart facts wrong, handing them the data only helps a little, and they get worse as charts get busier.

Short answer: compute the description from the chart's data with rules. It cannot invent a number, it costs almost nothing to run, and every sentence can be checked against a downloadable table.

04 / BEST PRACTICE

How to do it.

The same six steps work for any dashboard or report where the data behind the chart already exists.

  1. Start from the data

    Use the data behind the chart, not a picture of it, whenever the data exists.

  2. Compute the facts

    Write the core description with rules: direction, highs and lows, biggest change, comparisons.

  3. State the thresholds

    Say what counts as "rising" or "roughly flat," so readers know the rule, not a judgment call.

  4. Ship the table

    Put an accessible data table and a download next to every chart.

  5. Test every rule

    Check each rule on hand-checked charts, including ties, gaps and flat lines.

  6. Label any AI

    If you add AI, label it, and check every number it states against the data before showing it.

i

Where AI still helps.

Answering a reader's follow-up questions, clearly labeled. Charts that exist only as images or PDFs, with extracted numbers checked by a person. Suggesting context that a person reviews. AI may get there; when you already have the data, readers shouldn't depend on it today.

The bigger lesson
is about meaning.

Most of these errors come from the model not knowing what the numbers stand for. That points past charts: document what our data means, and any tool, AI or not, can use it correctly.

01 / MEASURE

Audit by level

Score Chart Details against LLM descriptions on 100+ real charts, sentence by sentence and level by level, with every fact checked against the data.

02 / EXTEND

Rules for Level 3

Add plain-language trend and distribution rules, the content blind readers ranked most useful.

03 / TEST

With screen-reader users

Compare accuracy, time and trust against the published baselines, with readers choosing their level of detail.

04 / FIX THE DATA

Make the data ready

Apply the same idea to the warehouse: a semantic layer so every tool knows what each number means.

Why measure our own charts. Benchmarks use other people's charts and single questions. A result on our own charts, with every statement checked, is the number that should decide what we deploy.
