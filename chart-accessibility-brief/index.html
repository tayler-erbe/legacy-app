Tayler Erbe / Research brief · Accessible charts

If you have the data, describe the chart from the data.

I first built accessible chart descriptions with AI. Then I read the research. Even the best models still get chart facts wrong, including when they are handed the data, and they get worse as charts get busier.

Short answer: compute the description from the chart's data with rules. It cannot invent a number, it costs almost nothing to run, and every sentence can be checked against a downloadable table.

05 / Best practice

How to do it.

Build it this way

  1. Start from the data, not the picture, whenever the data exists.
  2. Write the core description with rules: direction, highs and lows, biggest change, comparisons.
  3. State your thresholds, such as what counts as "rising" or "roughly flat."
  4. Ship the data table and a download next to every chart.
  5. Test each rule on hand-checked charts, including ties, gaps and flat lines.
  6. If you add AI, label it and check every number it states against the data.

Where AI still helps

  • Answering a reader's follow-up questions, clearly labeled as AI.
  • Charts that exist only as images or PDFs, with the extracted numbers checked by a person.
  • Suggesting context that a person then reviews.

AI may get there. Today, when you already have the data, there is no reason to make readers depend on it.

06 / Next

The bigger lesson is about meaning.

Most of these errors come from the model not knowing what the numbers stand for. That points past charts to a larger fix: documenting what our data means so that any tool, AI or not, can use it correctly.
